3. Deterministic 5-Stage RAG Pipeline

  1. Approved Ingestion: Indexed KMS docs with owner metadata (never raw student records).
  2. Hybrid BM25 / Vector Retrieval: Top chunks scored against confidence threshold.
  3. Deterministic Guardrails (Non-LLM): Regex + rule layer intercepts appeals, hardship, wellbeing, PII & prompt injections before LLM generation.
  4. Bounded Edge LLM / Extractive Quote: Answers strictly from retrieved chunks with inline section citations.
  5. Ticketing Handoff + Audit: Low-confidence/sensitive queries package context into Staff Ticket Queue & redact PII pre-log.
